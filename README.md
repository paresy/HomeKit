Folgende Module beinhaltet das Symcon HomeKit Repository:

- __HomeKit Bridge__ ([Dokumentation](docs))
    Die Bridge stellt Variablen aus Symcon als Geräte in Apple HomeKit bereit und kümmert sich um das Koppeln und die Kommunikation mit der Home-App, Siri und den HomeKit-Steuerzentralen.

Ab Version 2.0 wird Symcon 9.1 oder neuer benötigt.
